# 柚子Vibe 0.1.0 (24)

- 新增 OMP（Oh My Pi）助手入口，读取电脑端供应商模型及实际支持的思考档位。
- 支持原生历史与图片导入、会话恢复、流式回复、工具审批、提问、文件附件及用量展示。
- Normal / Plan / Trust 使用 OMP 工具审批桥；Plan 拒绝写入，立即发送中断成功后继续队列，普通停止暂停队列。
- 第三方网关的凭据只保存在电脑私有目录，未包含在 App 或仓库中。

验证：111 项连接器测试、127 项 iOS 测试通过；真实网关完成审批写入、Plan 拒绝写入、重启恢复原会话及本地命令输出验证。能力边界见 [OMP 接入说明](OMP.md)。

发布状态：2026-09-14 API 密钥上传成功。Apple API 已确认 Build 24 为 VALID、INTERNAL_ONLY、IN_BETA_TESTING，已进入内部测试。后续 OMP 手机配置页改动不包含在此构建中。
