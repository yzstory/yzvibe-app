# 回复朗读

默认使用 iOS AVSpeechSynthesizer 和系统语音，不请求麦克风权限、不上传回复、不调用 Codex / Claude，也不产生额外对话 token。系统语音资源与设备有关，不能等同于 Siri 或保证所有设备音色相同。

助手回复完成后显示“朗读”，再次点按停止；长按菜单也提供入口。一次只播放一条，切换会话、离开聊天、进入后台、开始语音输入、音频中断或拔下耳机会停止。第一版不提供锁屏持续朗读。

只取 assistant 消息的正文。工具调用参数、工具输出、tool 角色和附件不进入朗读输入。正文额外过滤围栏代码（含未闭合围栏）、缩进代码、行内代码、常见终端命令、带时间戳/日志级别的行以及命令/日志标题段落。标题、列表、链接显示文字和表格文字保留，URL 和图片不读。不调用模型改写或总结。

未标记、混在自然语言中的任意日志不能靠规则完美识别；优先依赖消息结构隔离工具内容，规则只处理常见 Markdown 格式。行内代码整体跳过，包含其中的技术标识或文件名。

ReplySpeechProvider 预留替换实现接口。未来若增加云端 TTS，可在这个接口下接入；当前没有云端地址、密钥或自动回退。云端可以提供更丰富的语气/情绪控制和流式音频，但需联网、传输正文并按供应商计费，不需要重新运行对话模型。

验证覆盖正文过滤、日志章节边界、未闭合代码、朗读替换、迟到回调、停止与失败恢复。真实设备的系统音色、耳机和电话中断仍须听测。
