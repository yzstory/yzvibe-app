# iOS 0.1.0 (14)

## 改进

- 设备页和聊天页区分正在重连、原隧道地址不可用、配对凭据失效。普通超时不会判定地址失效，提供重试、局域网找回和更新地址入口。
- 聊天输入栏分别提供命令、技能面板。
- 附件菜单支持照片、拍摄、系统文件选择器。文件保留原始字节及名称，接入草稿与可靠待发送箱；支持文件预览。每条消息最多 6 个附件，总大小不超过 20 MB。
- 连接器支持非图片附件，将文件路径提供给 Agent，持久保存附件元数据并随过期文件清理。需要同步更新连接器。

## 验证

- 连接器 91 项测试通过。
- iOS 106 项测试通过（53 XCTest + 53 Swift Testing）。
- 模拟器 App 编译通过，已检查附件菜单、系统文件选择器与技能面板。真机拍摄仍待验证。
