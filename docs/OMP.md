# OMP 接入

连接器通过 Oh My Pi 的 NDJSON RPC 接入，已验证版本 **18.1.20**。官方项目：https://github.com/can1357/oh-my-pi 。不复用 Codex App Server 协议。

## 安装与模型

使用官方安装方式安装 `omp`；连接器依次使用 `YZVIBE_OMP_BIN`、`~/.local/bin/omp`、PATH 中的 `omp`。

第三方 OpenAI 兼容服务在电脑的 `~/.omp/agent/models.yml` 配置，`baseUrl` 填 `/chat/completions` 之前的地址。密钥放电脑私有目录，通过 `apiKey: "!cat /absolute/private/key-file"` 引用。配置和密钥权限设为 0600，密钥目录 0700；不要提交到 Git。

在 `~/.omp/agent/config.yml` 的 `modelRoles.default` 设置 `provider/model`。手机新建会话选择 **OMP**，模型来自已配置供应商。无法探测目录时显示空列表，不冒用 Claude/Codex 模型。

`contextWindow` 是 OMP 配置预算，不能直接视为服务商核验的容量；未确认的第三方模型应设置保守预算。图片输入和可调 thinking 档位必须按供应商真实能力配置。模型会输出 reasoning tokens 不代表兼容 `reasoning_effort` 参数。

## 行为

- 独立 RPC 子进程持续接收文本、工具状态、提问与用量。v2 大消息分片重组；启动、请求、中断均有超时。
- 原生历史按活动分支导入；恢复保留原生 ID。原生图片 Blob 转入带鉴权的附件接口。列表读取头尾缓存，打开时最多读取 64 MB；过大历史明确报错，不静默截成错误分支。
- 现有持久化发送回执、队列和断线后待确认状态继续适用。立即发送沿用“中断当前轮，再发送队首消息”；不是 OMP 原生的轮内 steer。普通停止保留并暂停队列，中断未确认不会自动重发。
- 手机重命名即时持久化显示名，下次发送同步到 OMP 原生标题。删除沿用本项目隐藏/归档语义，不删除电脑原始历史。
- 文字、普通文件路径和支持视觉的模型图片输入均接入。OMP 入站 RPC 单帧约 1 MiB；超过限制明确提示减少附件，不能静默丢图。
- 工具卡、Markdown、复制、朗读、语音输入、草稿、文件浏览、Git diff、交付记录和活动状态复用已有 App 链路。
- 手机支持 `/compact`、`/context`、`/usage`、`/help`、`/skill:名称`；其余原生命令留在电脑端，避免本地命令绕过工具审批。技能扫描全局与工作目录的 `.omp/skills`。
- 不同供应商没有统一账户余额接口，额度页明确提示不可用，不展示其他 Agent 的额度。价格未验证时不编造费用。

## 审批与限制

YzVibe 启动时仅为自己的 OMP 子进程加载私有 trusted extension，不修改全局扩展。加载握手失败、审批桥不可用或扩展报错时停止/拒绝执行。

- Normal：本地 read/grep/find/ls 自动允许；其他工具进入手机审批，可使用现有规则。
- Plan：只允许本地读取与搜索；Shell、写入、网络/扩展工具直接拒绝，规则不会覆盖此限制。
- Trust：工具直接执行；交互问题仍发到手机回答。

这是工具执行拦截，不是操作系统沙箱。电脑上安装的扩展代码本身仍受用户信任；批准 task 等委派工具意味着批准该工具所执行的委派任务，不承诺所有子代理内部工具都逐项弹出手机审批。

OMP 没有跨终端写入锁。恢复时会检查同目录独立 OMP 进程并提示先退出，但此检查不能消除检查后另开终端的竞争。不要在手机和独立终端同时写同一会话。

## 验证

离线回归覆盖 RPC 响应关联/晚到错误/分片/断线、Plan 策略、模型能力、活动分支、图片 Blob、中断队列和工具失败状态。真实网关测试覆盖模型回复、读取、Normal 审批写入、Plan 拒绝写入、重启恢复同一原生会话。iOS 真机推送和灵动岛展示仍需安装包含本改动的 App 后验证。

## 手机配置（Build 24 之后）

「我 → 模型列表 → OMP」按当前电脑展示 `models.yml` 中明确列出的模型，无内置模型预设。可以添加 OpenAI 兼容模型，填写 Base URL、API Key、Model Name；完整 `/chat/completions` 地址会规范化。更新现有供应商会保留其他字段和供应商，模型 ID 不变；同供应商模型共享 URL 和密钥。

手机通过 HTTPS 和已有配对鉴权提交到 `/agents/omp/config`。GET 仅返回 URL、模型名、可编辑状态和是否已有 Key，不返回 Key 或取密钥命令。Key 留空保留原值，更改 URL 时须重新输入 Key。Key 只存在表单内存，服务端以 0600 独立文件保存；YAML 使用 OMP 原生 `!cat` 引用。配置使用版本校验和原子替换，冲突要求刷新。保存不会调用模型验证或产生模型费用。

保存后手机会话下一轮重建 OMP 子进程并恢复同一会话；不打断运行中任务。独立终端重新打开 OMP 后加载。新模型采用纯文本与保守 32768 上下文预算，实际视觉/思考能力由终端配置决定。非 OpenAI 兼容供应商仍可读取，编辑请在终端完成。此功能不修改终端默认模型角色。
