# 回复中的本地文件预览

回复里的 Markdown 本地链接、行内代码路径、普通文字文件路径、`file://` 与 `sandbox:` 文件链接会在 App 内打开。HTTP/HTTPS 外链交给系统浏览器；本地路径指向会话所属电脑。

- Markdown 默认渲染标题、列表、表格、代码块和图片，可切换源码。文档内相对文件和图片链接以当前文档目录为基准。
- 图片直接预览，点图片可全屏缩放；UIImage 不支持的原生文档格式交给 Quick Look。
- 视频先下载到临时文件，再使用 iOS 播放器播放；不把完整视频加载成内存 Data。较大文件需要等待下载，不能播放的编码显示明确提示，并保留下载入口。
- 中文、空格、`&`、`#` 等文件名通过独立查询参数编码传输；源代码引用的 `:行号`/`#L行号` 自动移除。
- 工作目录、用户主目录里的非敏感文件可读取；临时目录只扩展 Markdown、图片、视频。符号链接检查及凭据文件拦截继续生效，新增 OMP secrets 与 App Store Connect 私有目录拦截。
- 预览失败可重试或下载。Markdown/代码内嵌预览保持 2 MB 上限，较大的文档可下载。

需要同时更新 App 和电脑连接器。文件必须仍存在于对应电脑；无法访问另一台机器的路径或已清理的临时文件。
