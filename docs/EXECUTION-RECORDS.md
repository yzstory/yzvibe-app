# 轻量执行记录

聊天页只展示回复，不再追加交付卡。通过「更多 → 执行记录」查看最近 50 轮；打开列表才请求索引，打开某一轮才读取详细内容。会话快照和结束事件不再自动拉取历史。

新记录保存轮次 ID、状态、时间、消息引用和产物路径，不复制回答、工具输出或文件列表。详情从原消息还原，没有额外模型请求。工具状态更新不再为此重写 sessions.json。

每个会话最多保留 50 个轮次索引；淘汰索引不删除原始聊天消息。旧记录仅在所有关联消息仍可读取时移除重复数据，否则保留旧字段作为恢复来源。此迁移在连接器启动时执行。

接口：
- `GET /sessions/:id/runs?summary=1`：轻量索引，兼容字段 tools/files/summary 为空。
- `GET /sessions/:id/runs/:runId`：单轮完整详情；索引已过期时返回 404。
- 原 `GET /sessions/:id/runs` 继续为旧客户端返回完整记录。

旧连接器不认识单轮接口时，新 App 回退读取原列表。此时网络开销仍取决于旧连接器，升级双方后才完整生效。

验证：连接器 89 项、iOS 101 项测试通过。新增覆盖索引限额、原消息保留、旧数据迁移、详情还原以及新旧 HTTP 接口。无新增 AI 总结或模型 token 消耗。
