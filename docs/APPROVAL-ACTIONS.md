# 审批卡与会话信任

2026-09-13：补齐 iOS 审批卡和 Connector 0.1.2。

- 「总是允许…」改为明显的整行菜单，Codex 文件修改也返回会话规则选项。保存后在「我 → 审批规则」管理、左滑撤销。
- 复杂命令提供“完整命令匹配”；简单命令可选前缀。权限范围无法用现有规则匹配的请求显示说明，提问必须由用户回答。
- 「信任此会话 · Trust」直接确认模式并允许当前及同会话待处理操作；其他会话保持原模式。沿用已有 Face ID 设置。
- Trust 在当前轮通过连接器自动响应后续权限请求，原生 Agent 权限参数在下一轮应用；不重启当前任务。需要回答的问题保留。
- 规则写盘失败不会再假报成功或提前放行；旧审批、已过期审批和提问卡不能触发 Trust。

需要同时更新 App 和电脑连接器。旧连接器仍支持原有“允许/拒绝”；新 Trust 入口遇到旧接口时会提示更新，不假装已经切换模式。
