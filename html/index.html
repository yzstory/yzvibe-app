01 / 工作随身

换个地方，
接着推进。

Claude Code、Codex 和 OMP，在手机上共用一个入口。按项目整理会话，选择模型、补充想法，电脑继续执行。

过程一目了然

连续工具调用收进一张卡片，需要时再展开。上下文用量、执行记录和任务状态，随时查看。

决定留给你

查看需要批准的操作，再选择允许或拒绝。支持按范围保存规则，减少重复确认。

连接有据可查

在设备页切换地址、检查连接和配置。电脑保持开机，手机就能继续访问熟悉的工作区。

02 / 看见成果

不止看回复，
也看它做了什么。

查看文件改动与交付记录，点开回复里的文档、图片或视频。HTML 也能直接呈现为页面，查看样式、图片与交互，不必对着源码猜效果。

HTML 预览需搭配新版连接器，支持同目录内的本地资源；依赖在线 API 或 CDN 的页面需先生成本地静态产物。

你的电脑，还是工作现场。

无需柚子Vibe账号，会话与工作文件留在电脑。模型请求由电脑上的 Agent 发往对应服务。

03 / 开始使用

两步，
把工作带在身边。

  1. 在电脑启动连接器

    准备 Node.js 20+，并安装、登录你要使用的 Claude Code、Codex 或 OMP。

    电脑终端
    npx yzvibe@latest start

    默认尝试远程隧道，也可加 --access=local 在同一 Wi-Fi 下连接。已有连接器请等任务结束后执行 npx yzvibe@latest restart 更新。

  2. 在手机安装 App，扫码配对

    安装后打开「设备」，扫描电脑终端里的配对二维码。
