01 / 随时接着做

工作继续，
节奏由你。

电脑上的 Agent 还在工作，你不必一直坐在电脑前。柚子Vibe 把 Claude Code、Codex 和 OMP 的会话带到 iPhone 上，让你换个地方，也能接着推进手里的项目。

新建一个任务，或打开终端里聊过的会话。选好工作目录和模型，用分档滑条调整思考力度，补充一句想法，剩下的交给电脑继续完成。

多个项目，一眼有数

按文件夹整理会话，切换已配对的电脑，随时查看哪些任务正在运行、等待审批或已经完成。

从进度，到结果

按需查看工具输出、交付记录和文件 diff；原生选区支持连续正文跨段落复制，回复也能一键复制。

常用工具，一个入口

星光菜单集合照片、拍摄、文件、命令行和技能。发送参考图或文件，也能浏览、预览并下载电脑上的成果。

02 / 三种助手

习惯的助手，
同一个入口。

Claude Code、Codex 和 OMP（Oh My Pi），都能在柚子Vibe 中新建或继续会话。选择适合任务的助手，查看流式回复、工具执行、审批和用量，无需在手机上重新搭建工作环境。

OMP 读取电脑端明确配置的模型与思考档位。也可以在「我 → 模型列表 → OMP」中，通过 HTTPS 为已配对电脑添加 OpenAI 兼容模型，填写接口地址、密钥和模型名。

密钥不回显，保存不会调用模型验证。手机下一轮消息应用新配置，独立终端需重开 OMP。OMP 使用工具审批拦截，不是系统沙箱；不要在手机和独立终端同时写入同一会话。

03 / 直接看成果

文档、图片、视频，
点开就能看。

Agent 回复里的本地文件路径，可以直接在 App 内打开。Markdown 默认呈现排好版的正文，也能切换源码；相对链接和图片按文档所在目录解析。

图片可全屏缩放，视频下载后用原生播放器播放。中文、空格和特殊字符文件名也能正确定位，外部网页链接继续交给浏览器。

文件来自会话所属电脑，需仍然存在且可访问。Markdown 与代码内嵌预览上限为 2 MB，更大的文档可以下载；视频需等待下载，播放能力取决于编码支持。

04 / 说与听

说出想法，
听见回复。

按住「语音」说出想法，松手后文字留在输入框里，修改、确认，再发送。上滑即可取消，滑回继续说，原有草稿也会保留。

回复可以用 iOS 原生语音朗读，自动过滤代码块、常见命令和日志。随时停止或切换回复，让你不用一直盯着屏幕。

语音输入使用 Apple 端侧识别，录音不上传到连接器；需要麦克风、语音识别权限及设备和语言支持。识别不可用时不会转用云端服务。录音与朗读不会同时进行。

05 / 掌握每一步

关键操作，
由你决定。

需要额外权限时，审批请求会来到聊天中，也会汇集到审批收件箱。先看清 Agent 想执行的命令，再选择允许或拒绝；拒绝时，还可以告诉它原因。

熟悉的操作可以设为有范围和期限的放行规则，随时撤销；高风险审批支持 Face ID 确认。也可以将当前会话切换为 Trust，允许 Agent 直接执行操作。

配置推送后，待审批和最终回复完成的消息会来到锁屏。通知开关按设备同步，中间工具轮次不再反复提醒；锁屏与灵动岛也能展示任务状态。

Trust 会跳过权限检查，Codex 同时跳过沙箱；请按任务需要选择。

让 Agent 继续做事，
让重要的决定留在你手里。

06 / 本地优先

还是你的电脑。
还是熟悉的工作区。

无需柚子Vibe 账号，也不必把项目搬进新的云端工作区。桌面连接器在你的电脑上运行 Agent，iPhone 负责交互与展示，会话记录和工作文件保留在电脑上。短暂断线时，待发送箱与接收对账帮助恢复投递；回到前台后补齐消息，地址失效时也有局域网找回和更新地址入口。

开始使用

下一个想法，
不必等回到桌前。

在电脑上启动连接器，再用 iPhone 配对。首次使用可以先体验 App 内的演示数据。建议搭配当前 Connector 0.1.3，以使用 OMP、文件预览、审批规则和通知偏好等功能。

  1. 启动桌面连接器

    需要 Node.js 20+，并提前安装、登录 Claude Code、Codex 或 OMP。默认通过 Cloudflare 临时隧道连接，让手机离开同一 Wi-Fi 也能继续使用。

    Terminal
    npx yzvibe@latest start

    无需克隆仓库；首次运行 npx 会提示安装，启动后终端可以关闭。推荐先安装 cloudflared（macOS：brew install cloudflared）。连接器也会尝试通过 npx 启动它；若远程隧道无法启动，则回落到局域网模式。

    已有连接器时，等任务完成后运行 npx yzvibe@latest restart 升级；只运行 start 不会替换已有进程。长期常驻建议 npm install -g yzvibe@latest，再用 yzvibe install 注册自启。迁移安装路径后需重新注册服务。

    选择适合你的连接方式

    Cloudflare 默认

    自动生成临时 HTTPS 地址，适合在外用手机连接电脑。隧道重建后地址可能变化，可重新显示二维码配对。

    npx yzvibe@latest start
    局域网

    手机和电脑在同一 Wi-Fi 下直接连接，适合在家或办公室使用。

    npx yzvibe@latest start --access=local
    自有域名 / 隧道

    已有配置好的反向代理或隧道时，使用自己的固定 HTTPS 地址。该参数不会自动创建域名或配置隧道。

    npx yzvibe@latest start --access=https://your-host.example
    Tailscale

    手机与电脑加入同一 tailnet，通过电脑的 Tailscale IP 连接。将示例地址替换为电脑的实际 IP。

    npx yzvibe@latest start --access=100.x.x.x

    连接器已在运行时，将 start 换成 restart 以应用新参数。运行 npx yzvibe@latest qr 可再次显示配对二维码。

  2. 安装 iOS App，扫码配对

    iOS 0.1.0 (28) 已上传，Apple 后续处理和可安装状态待核验；最近确认可供内部测试的是 build 27。非内部测试成员可从源码用 Xcode 编译并安装到 iPhone，在「设备 → 扫码配对」中扫描终端二维码，即可开始会话。
