01 / 随时接着做

工作继续，
节奏由你。

电脑上的 Agent 还在工作，你不必一直坐在电脑前。柚子Vibe 把 Claude Code 和 Codex 的会话带到 iPhone 上，让你换个地方，也能接着推进手里的项目。

新建一个任务，或打开终端里聊过的会话。选好工作目录，补充一句想法，剩下的交给电脑继续完成。

多个项目，一眼有数

按文件夹整理会话，切换已配对的电脑，随时查看哪些任务正在运行、等待审批或已经完成。

从进度，到结果

读回复、看工具输出和文件 diff；发一张参考图，也能浏览、预览并下载电脑上的文件。

02 / 掌握每一步

关键操作，
由你决定。

需要额外权限时，审批请求会来到聊天中，也会汇集到审批收件箱。先看清 Agent 想执行的命令，再选择允许或拒绝；拒绝时，还可以告诉它原因。

熟悉的操作可以设为可撤销的放行规则，高风险审批支持 Face ID 确认。配置推送后，待审批和回复完成的消息，也能出现在锁屏上。

让 Agent 继续做事，
让重要的决定留在你手里。

03 / 本地优先

还是你的电脑。
还是熟悉的工作区。

无需 柚子Vibe 账号，也不必把项目搬进新的云端工作区。桌面连接器在你的电脑上运行 Agent，iPhone 负责交互与展示，会话记录和工作文件保留在电脑上。

开始使用

下一个想法，
不必等回到桌前。

在电脑上启动连接器，再用 iPhone 配对。首次使用可以先体验 App 内的演示数据。

  1. 启动桌面连接器

    需要 Node.js 20+，并提前安装、登录 Claude Code 或 Codex。默认通过 Cloudflare 临时隧道连接，让手机离开同一 Wi-Fi 也能继续使用。

    Terminal
    git clone https://github.com/yzstory/yzvibe-app.git
cd yzvibe-app/connector
npm install
node bin/yzvibe.js start

    推荐先安装 cloudflared（macOS：brew install cloudflared）。连接器也会尝试通过 npx 启动它；若远程隧道无法启动，则回落到局域网模式。

    选择适合你的连接方式

    Cloudflare 默认

    自动生成临时 HTTPS 地址，适合在外用手机连接电脑。隧道重建后地址可能变化，可重新显示二维码配对。

    node bin/yzvibe.js start
    局域网

    手机和电脑在同一 Wi-Fi 下直接连接，适合在家或办公室使用。

    node bin/yzvibe.js start --access=local
    自有域名 / 隧道

    已有配置好的反向代理或隧道时，使用自己的固定 HTTPS 地址。该参数不会自动创建域名或配置隧道。

    node bin/yzvibe.js start --access=https://your-host.example
    Tailscale

    手机与电脑加入同一 tailnet，通过电脑的 Tailscale IP 连接。将示例地址替换为电脑的实际 IP。

    node bin/yzvibe.js start --access=100.x.x.x

    连接器已在运行时，将 start 换成 restart 以应用新参数。运行 node bin/yzvibe.js qr 可再次显示配对二维码。

  2. 安装 iOS App，扫码配对

    目前提供源码构建方式。用 Xcode 编译并安装到 iPhone，在「设备 → 扫码配对」中扫描终端二维码，即可开始会话。
